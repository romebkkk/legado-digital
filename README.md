# 🕊️ Legado Digital

> Create a digital-legacy plan so your family isn't locked out: what to do with each account, who is in charge and where information lives — with a built-in password/seed-phrase detector so you never write secrets.

**Free · open source · 100% in your browser (nothing is uploaded).**

<sub>[🇪🇸 Español abajo](#-español)</sub>

## Features
- Printable plan
- secret detector
- 100% local

## Use
Open `index.html` — no install, no server, no build. Host it free on GitHub Pages.

## Basis
Buenas prácticas de herencia digital (contactos de legado de Google/Apple/Meta).

## ⚠️ Disclaimer
Orientative tool — not legal, tax or financial advice. Check your specific case with a professional.
